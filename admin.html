Acesso ao painel

Cole abaixo um Personal Access Token do GitHub. Ele fica salvo apenas neste navegador (localStorage) — nunca é enviado para nenhum servidor além do próprio GitHub.

Como gerar (uma vez só, dura o quanto você definir):

  1. Acesse github.com/settings/personal-access-tokens/new (Fine-grained token).
  2. Em Repository access, selecione Only select repositories → portfolio-thiago-ribeiro.
  3. Em Permissions → Repository permissions, defina Contents: Read and write.
  4. Gere e copie o token, cole aqui em cima.
